**Stage:** visual product concept, not a live adult content or commercial service.
**Source:** `partner-preview.html` (self-contained, no external scripts, images, tracking or redirects).

## What a prospective affiliate network can review
- Accessible mobile and desktop dark-theme design
- Six abstract sample thumbnail/advertisement placements
- Studios, Live and Membership category filters
- Visitors click a thumbnail to visit the advertiser's own site (only after approval)
- Clear affiliate commission disclosure
- Licensed-creative, age, location, privacy and content-review policies
- No adult images, videos, feeds, embeds, external redirects, cookies or visitor checkout

## Before submitting partnership application
1. Inform the affiliate program this is a **pre-launch, non-explicit concept**, not an operating traffic source.
2. Ask whether a concept URL is acceptable or if they require a live branded domain.
3. If a branded domain is mandatory, deploy only an abstract, non-explicit review site on an explicitly permitted, fee-free host and attach a verified domain controlled by the Founder.
4. Never assume a temporary GitHub proxy URL satisfies production adult-business hosting rules.
5. Never switch on restricted thumbnails, affiliate links or worldwide access before contractual and legal approval.

## Draft concise description for applications
“After Dark is a pre-launch, mobile-first affiliate discovery directory. We plan to showcase only advertiser-approved promotional thumbnails that link visitors directly to advertisers' own platforms.
